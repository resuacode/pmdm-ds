# Sets en Kotlin

En Kotlin, un `Set` es una colección de elementos únicos, lo que significa que no puede contener elementos duplicados. Los `Set` creados con `setOf()` son de solo lectura: no se pueden añadir ni quitar elementos. Si al crearlo pasamos elementos repetidos, solo se guarda uno de cada.

```kotlin
val numeros = setOf(1, 2, 3, 4, 5)
```

En el ejemplo anterior, se crea un `Set` `numeros` con los valores `1, 2, 3, 4, 5`. Los `Set` en Kotlin se crean utilizando la función `setOf()` seguida de los valores del `Set` entre paréntesis.

## Acceso a elementos de un Set

Puedes acceder a elementos individuales de un `Set` utilizando la función `contains()` para comprobar si un elemento está presente en el `Set`.

```kotlin
val contieneTres = numeros.contains(3)
val contieneSeis = numeros.contains(6)
```

En el ejemplo anterior, se comprueba si el `Set` `numeros` contiene los elementos `3` y `6` utilizando la función `contains()`.

## Iteración sobre un Set

Puedes iterar sobre los elementos de un `Set` utilizando un bucle `for` o la función `forEach()`.

```kotlin
for (numero in numeros) {
    println(numero)
}

numeros.forEach { numero ->
    println(numero)
}
```

En el ejemplo anterior, se itera sobre los elementos del `Set` `numeros` utilizando un bucle `for` y la función `forEach()`.

## Modificación de elementos de un Set

Como los `Set` creados con `setOf()` son de solo lectura, no puedes modificar sus elementos una vez que se ha creado. Si necesitas un `Set` mutable, puedes utilizar la función `mutableSetOf()`.

```kotlin
val numeros = mutableSetOf(1, 2, 3, 4, 5)
numeros.add(6)  // true: se añade
numeros.add(3)  // false: ya existía, no se añade
numeros.remove(1)
```

En el ejemplo anterior, se crea un `Set` mutable `numeros` con los valores `1, 2, 3, 4, 5`, se añade el valor `6` al `Set` utilizando la función `add()` y se elimina el `1`. La función `add()` devuelve `false` si el elemento ya estaba en el conjunto.

## Operaciones con Sets

Los `Set` en Kotlin proporcionan una serie de operaciones útiles, como `size` para obtener el tamaño del `Set`, `contains` para comprobar si un elemento está presente en el `Set`, `union` para unir dos `Set`, `intersect` para obtener la intersección de dos `Set`, etc.

```kotlin
val numeros = setOf(1, 2, 3, 4, 5)
val numerosPares = setOf(2, 4, 6, 8, 10)
val numerosImpares = setOf(1, 3, 5, 7, 9)

val union = numeros union numerosPares              // [1, 2, 3, 4, 5, 6, 8, 10]
val interseccion = numeros intersect numerosImpares // [1, 3, 5]
val diferencia = numeros subtract numerosPares      // [1, 3, 5]
val diferenciaSimetrica = (numeros union numerosPares) subtract (numeros intersect numerosPares) // [1, 3, 5, 6, 8, 10]

val contieneTodos = numeros.containsAll(setOf(1, 2))    // true: {1, 2} es subconjunto de numeros
val contieneAlguno = numerosPares.any { it in numeros } // true
val sonDisjuntos = numerosPares.none { it in numerosImpares } // true
val esVacio = numeros.isEmpty()                         // false
```

En el ejemplo anterior, se utilizan varias operaciones de conjuntos con los `Set` `numeros`, `numerosPares` y `numerosImpares`. Las funciones `union`, `intersect` y `subtract` pueden llamarse de forma normal (`numeros.union(numerosPares)`) o, como en el ejemplo, en notación infija.

Estas operaciones sirven para lo siguiente:

- `union()`: Devuelve un `Set` que contiene todos los elementos de los dos conjuntos.
- `intersect()`: Devuelve un `Set` que contiene los elementos comunes de los dos conjuntos.
- `subtract()`: Devuelve un `Set` que contiene los elementos del primer conjunto que no están en el segundo.
- La **diferencia simétrica** (elementos que están en uno de los conjuntos pero no en ambos) no tiene una función propia, pero se obtiene combinando las anteriores.
- `containsAll()`: Comprueba si un `Set` contiene todos los elementos de otra colección, es decir, si esta es un subconjunto suyo.
- `any { it in otro }`: Comprueba si hay al menos un elemento en común.
- `none { it in otro }`: Comprueba si dos conjuntos son disjuntos, es decir, si no tienen elementos en común.
- `isEmpty()`: Comprueba si un `Set` está vacío.

Los `Set` en Kotlin son una forma eficiente de almacenar y manipular colecciones de elementos únicos. Puedes utilizar las operaciones proporcionadas por los `Set` para realizar operaciones comunes, como unir, intersecar, restar y comparar `Set` entre sí.

Si necesitas un `Set` mutable, puedes utilizar la función `mutableSetOf()` para crear un `Set` que puedas modificar. Los `Set` en Kotlin son una herramienta poderosa que te permite trabajar con colecciones de elementos únicos de forma eficiente y concisa.
