# Funciones componibles en Jetpack Compose

En Jetpack Compose, las interfaces de usuario se crean a partir de funciones componibles. Estas funciones no devuelven nada (su tipo de retorno es `Unit`), sino que **emiten** elementos de la interfaz de usuario al ejecutarse. Puedes componer estas funciones para crear interfaces de usuario complejas y reutilizables.

## Crear una función componible

Para crear una función componible en Jetpack Compose, utiliza la anotación `@Composable` antes de la definición de la función. Una función componible puede tener parámetros y puede llamar a otras funciones componibles. Por convención, su nombre empieza por mayúscula, como si fuera una clase.

```kotlin
@Composable
fun Greeting(name: String) {
    Text(text = "Hello, $name!")
}
```

En el ejemplo anterior, se define una función componible `Greeting` que toma un parámetro `name` de tipo `String` y muestra un elemento de texto `Text` con un saludo personalizado.

## Componer funciones componibles

Puedes componer funciones componibles para crear interfaces de usuario más complejas. Utiliza las funciones de composición proporcionadas por Compose, como `Column`, `Row`, `Box`, `Spacer`, etc., para organizar y diseñar los elementos de la interfaz de usuario.

```kotlin
@Composable
fun GreetingList(names: List<String>) {
    Column {
        names.forEach { name ->
            Greeting(name = name)
        }
    }
}
```

En el ejemplo anterior, se define una función componible `GreetingList` que toma una lista de nombres y muestra un saludo personalizado para cada nombre utilizando la función componible `Greeting`.

## Actualización de funciones componibles

Las funciones componibles en Jetpack Compose son reactivas, lo que significa que se vuelven a ejecutar automáticamente cuando cambian los datos de los que dependen (sus parámetros o el estado que leen). A este proceso se le llama **recomposición**. Esto permite que la interfaz de usuario se actualice de forma dinámica en respuesta a los cambios en los datos.

```kotlin
@Composable
fun Counter(count: Int) {
    Text(text = "Count: $count")
}
```

En el ejemplo anterior, se define una función componible `Counter` que muestra el recuento actual. Cuando el composable que llama a `Counter` le pasa un valor distinto de `count`, la función se vuelve a ejecutar automáticamente para reflejar el nuevo valor. Veremos cómo guardar y modificar ese valor en el apartado de [gestión del estado](./22-state-management.mdx).

## Columnas y filas en Jetpack Compose

Jetpack Compose proporciona las funciones `Column` y `Row` para organizar elementos de la interfaz de usuario en columnas y filas respectivamente. Puedes anidar columnas y filas para crear diseños más complejos y reutilizables.

```kotlin
@Composable
fun GreetingList(names: List<String>) {
    Column {
        names.forEach { name ->
            Greeting(name = name)
            Spacer(modifier = Modifier.height(8.dp))
        }
    }
}
```

En el ejemplo anterior, se utiliza la función `Column` para organizar los saludos en una lista vertical. Se añade un `Spacer` entre cada saludo para separarlos visualmente.

## Modificadores en Jetpack Compose

Jetpack Compose utiliza modificadores para aplicar estilos y comportamientos a los elementos de la interfaz de usuario. Puedes utilizar modificadores para cambiar el tamaño, la posición, el color, la forma, etc., de los elementos de la interfaz de usuario.

```kotlin
@Composable
fun Greeting(name: String) {
    Text(
        text = "Hello, $name!",
        modifier = Modifier
            .padding(16.dp)
            .background(Color.Blue)
            .clickable { /* Acción al hacer clic */ }
    )
}
```

En el ejemplo anterior, se utiliza el modificador `padding` para añadir un relleno alrededor del texto, el modificador `background` para cambiar el color de fondo del texto, y el modificador `clickable` para añadir una acción al hacer clic en el texto.

:::warning[El orden de los modificadores importa]
Los modificadores se aplican en el orden en el que se encadenan. En el ejemplo anterior, como `padding` va **antes** que `background`, el relleno queda fuera del fondo azul (funciona como un margen). Si los intercambiamos, `Modifier.background(Color.Blue).padding(16.dp)`, el fondo azul ocupa también el relleno.

Por convención, todo composable que creemos debería aceptar un parámetro `modifier: Modifier = Modifier` y aplicarlo a su elemento raíz, para que quien lo use pueda ajustar su tamaño, posición, etc.
:::

## Recursos en Jetpack Compose

Jetpack Compose utiliza el sistema de recursos de Android para gestionar los recursos de la interfaz de usuario, como cadenas, colores, dimensiones, etc. Puedes acceder a los recursos utilizando las funciones `stringResource()`, `colorResource()`, `dimensionResource()`, `painterResource()`, etc.

```kotlin
@Composable
fun Greeting() {
    Text(
        text = stringResource(R.string.hello),
        color = colorResource(R.color.primary),
        modifier = Modifier.padding(dimensionResource(R.dimen.padding_medium))
    )
}
```

En el ejemplo anterior, se utiliza la función `stringResource()` para obtener una cadena de recursos, la función `colorResource()` para obtener un color de recursos, y la función `dimensionResource()` para obtener una dimensión de recursos (de tipo `Dp`).

:::tip[Usa siempre recursos para los textos]
Guardar los textos en `res/values/strings.xml` en lugar de escribirlos directamente en el código permite traducir la app a otros idiomas simplemente añadiendo un nuevo archivo `strings.xml` en la carpeta correspondiente (por ejemplo, `values-en`).
:::

## Temas en Jetpack Compose

Jetpack Compose utiliza el composable `MaterialTheme` para aplicar estilos coherentes (colores, tipografía y formas) a todos los componentes que contiene. Al crear un proyecto nuevo, Android Studio genera en el paquete `ui.theme` una función con el nombre de la app (por ejemplo, `MyAppTheme`) que envuelve a `MaterialTheme` con los colores y la tipografía del proyecto.

```kotlin
@Composable
fun MyAppTheme(content: @Composable () -> Unit) {
    MaterialTheme(
        colorScheme = lightColorScheme(),
        typography = Typography,
        shapes = Shapes(),
        content = content
    )
}

// En MainActivity
setContent {
    MyAppTheme {
        Greeting("Android")
    }
}
```

En el ejemplo anterior, se define un tema con un esquema de colores, una tipografía y unas formas, y se aplica a la aplicación envolviendo el contenido con él. Dentro del tema, los componentes pueden acceder a sus valores con `MaterialTheme.colorScheme`, `MaterialTheme.typography` y `MaterialTheme.shapes`. Lo veremos en detalle en el apartado de [Material Design](./25-material-design.mdx).

## Ejemplos de funciones componibles

### Ejemplo de función con Row

```kotlin
@Composable
fun Greeting(name: String) {
    Row {
        Text(text = "Hello, $name!")
        Spacer(modifier = Modifier.width(8.dp))
        Icon(Icons.Default.Favorite, contentDescription = null)
    }
}
```

En el ejemplo anterior, se utiliza la función `Row` para organizar el texto y el icono en una fila horizontal.

:::warning[Si `Icons.Default.Favorite` no se reconoce]
Los iconos de `Icons` no forman parte de Material 3, sino de la librería `material-icons-core`. Hasta la versión 1.4.0 de Material 3 (septiembre de 2025) llegaba incluida como dependencia de `material3`, pero ya no, así que en un proyecto nuevo Android Studio no encuentra `Icons` ni sus iconos. Hay dos formas de solucionarlo:

**Opción 1: añadir la librería de iconos.** Es lo más rápido y permite usar los ejemplos de los apuntes tal cual. En `gradle/libs.versions.toml`:

```toml
[libraries]
androidx-compose-material-icons-core = { group = "androidx.compose.material", name = "material-icons-core" }
```

Y en `app/build.gradle.kts`:

```kotlin
implementation(libs.androidx.compose.material.icons.core)
```

No lleva versión porque la gestiona el BOM de Compose (si no la resolviera, añade `version = "1.7.8"`). Esta librería incluye los iconos más habituales (`Add`, `Delete`, `Favorite`, `Home`, `Search`, `Settings`...), pero Google ya no la mantiene y no va a recibir iconos nuevos. Existe también `material-icons-extended` con el catálogo completo, pero pesa mucho y tampoco se mantiene, así que no conviene usarla.

**Opción 2: usar Material Symbols como recursos.** Es lo que recomienda Google actualmente. Se descarga el icono en formato Android (XML) desde [Material Symbols](https://fonts.google.com/icons), o se importa con *File → New → Vector Asset* en Android Studio, se guarda en `res/drawable` y se usa con `painterResource`:

```kotlin
Icon(painterResource(R.drawable.favorite), contentDescription = null)
```

Requiere un paso más por cada icono, pero da acceso a todo el catálogo actual sin depender de una librería congelada.
:::

### Ejemplo de función con Box

```kotlin
@Composable
fun Greeting(name: String) {
    Box(
        modifier = Modifier
            .background(Color.Blue)
            .padding(16.dp)
    ) {
        Text(text = "Hello, $name!", color = Color.White)
    }
}
```

En el ejemplo anterior, se utiliza la función `Box` para colocar el texto en un cuadro azul con un relleno de 16 dp.

### Ejemplo de función con Column

```kotlin
@Composable
fun GreetingList(names: List<String>) {
    Column {
        names.forEach { name ->
            Greeting(name = name)
            HorizontalDivider(thickness = 1.dp, color = Color.Gray)
        }
    }
}
```

En el ejemplo anterior, se utiliza la función `Column` para organizar los saludos en una lista vertical con una línea divisoria entre cada saludo. En Material 3, el antiguo `Divider` se ha sustituido por `HorizontalDivider` y `VerticalDivider`.

### Cómo añadir imágenes usando Image y painterResource

```kotlin
@Composable
fun Greeting(name: String) {
    Row {
        Image(
            painter = painterResource(id = R.drawable.ic_launcher_foreground),
            contentDescription = null,
            modifier = Modifier.size(48.dp)
        )
        Spacer(modifier = Modifier.width(8.dp))
        Text(text = "Hello, $name!")
    }
}
```

En el ejemplo anterior, se utiliza la función `Image` para añadir una imagen a la interfaz de usuario utilizando un recurso de imagen. El parámetro `contentDescription` es el texto que leen los lectores de pantalla; solo debe ser `null` en imágenes puramente decorativas.

:::tip[Imágenes desde internet]
`painterResource` solo carga imágenes de los recursos de la app. Para cargar imágenes a partir de una URL se utiliza una librería como [Coil](https://coil-kt.github.io/coil/compose/), con su composable `AsyncImage`.
:::

## Previews en Jetpack Compose

Jetpack Compose proporciona una función `@Preview` que te permite previsualizar tus funciones componibles en tiempo real en Android Studio. Puedes definir previsualizaciones para tus funciones componibles y ver cómo se ven en diferentes configuraciones y estados.

```kotlin
@Preview
@Composable
fun GreetingPreview() {
    Greeting(name = "World")
}
```

En el ejemplo anterior, se define una previsualización `GreetingPreview` para la función componible `Greeting` con el nombre "World". Puedes ver la previsualización en Android Studio y ajustarla según sea necesario.

### Opciones de previsualización

Jetpack Compose proporciona varias opciones de previsualización que te permiten personalizar la apariencia de tus previsualizaciones. Puedes definir diferentes configuraciones, tamaños, orientaciones, temas, etc., para tus previsualizaciones y ver cómo se ven en diferentes contextos.

```kotlin
@Preview(
    showBackground = true,
    name = "Greeting Preview",
    uiMode = Configuration.UI_MODE_NIGHT_YES,
    widthDp = 320,
    heightDp = 240
)
@Composable
fun GreetingPreview() {
    Greeting(name = "World")
}
```

Las opciones de previsualización son las siguientes:

- `showBackground`: Muestra un fondo en la previsualización.
- `name`: Nombre de la previsualización.
- `uiMode`: Modo de interfaz de usuario (claro, oscuro, etc.).
- `widthDp`: Ancho de la previsualización en dp.
- `heightDp`: Alto de la previsualización en dp.

## Opciones de alineación en Jetpack Compose

Jetpack Compose proporciona opciones de alineación que te permiten alinear los elementos de la interfaz de usuario de forma horizontal y vertical. Puedes utilizar las opciones de alineación para controlar la posición de los elementos en la pantalla y crear diseños más precisos y coherentes.

```kotlin
@Composable
fun Greeting(name: String) {
    Column(modifier = Modifier.fillMaxWidth()) {
        Text(
            text = "Hello, $name!",
            modifier = Modifier.align(Alignment.CenterHorizontally)
        )
    }
}
```

En el ejemplo anterior, se utiliza el modificador `align` para centrar horizontalmente el texto dentro de la columna.

:::info[`Modifier.align` depende del contenedor]
El modificador `align` solo está disponible dentro de un contenedor (`Column`, `Row` o `Box`) y acepta valores distintos en cada uno: dentro de una `Column` solo se puede alinear horizontalmente, dentro de una `Row` solo verticalmente y dentro de un `Box` en ambos ejes.
:::

### Opciones de alineación horizontal

Las opciones de alineación horizontal (se usan en `Column`) son las siguientes:

- `Alignment.Start`: Alinea el elemento al principio del eje horizontal.
- `Alignment.CenterHorizontally`: Alinea el elemento en el centro del eje horizontal.
- `Alignment.End`: Alinea el elemento al final del eje horizontal.

### Opciones de alineación vertical

Las opciones de alineación vertical (se usan en `Row`) son las siguientes:

- `Alignment.Top`: Alinea el elemento en la parte superior del eje vertical.
- `Alignment.CenterVertically`: Alinea el elemento en el centro del eje vertical.
- `Alignment.Bottom`: Alinea el elemento en la parte inferior del eje vertical.

En un `Box` se usan alineaciones en los dos ejes: `Alignment.TopStart`, `Alignment.Center`, `Alignment.BottomEnd`, etc.

### Opciones de alineación personalizadas

Además de las opciones de alineación predefinidas, Jetpack Compose te permite crear alineaciones personalizadas con `BiasAlignment`, indicando un desplazamiento en cada eje entre `-1f` (inicio) y `1f` (final), donde `0f` es el centro.

```kotlin
val CustomAlignment = BiasAlignment(horizontalBias = -0.5f, verticalBias = 0.5f)
```

En el ejemplo anterior, se define una alineación personalizada que coloca el elemento a medio camino entre el inicio y el centro en horizontal, y a medio camino entre el centro y el final en vertical.

### Uso de opciones de alineación en Column y Row

Puedes utilizar las opciones de alineación en las funciones `Column` y `Row` para alinear los elementos de la interfaz de usuario de forma horizontal y vertical.

```kotlin
@Composable
fun Greeting(name: String) {
    Row(
        verticalAlignment = Alignment.CenterVertically,
        horizontalArrangement = Arrangement.SpaceEvenly
    ) {
        Text(text = "Hello, $name!")
        Icon(Icons.Default.Favorite, contentDescription = null)
    }
}
```

En el ejemplo anterior, se utiliza la opción de alineación vertical `Alignment.CenterVertically` y la disposición horizontal `Arrangement.SpaceEvenly` para alinear el texto y el icono en una fila horizontal.

Las diferentes opciones de alineación y disposición te permiten crear diseños flexibles y personalizados en Jetpack Compose.

Para el Arrangement existen las siguientes opciones:

- `SpaceBetween`: Reparte el espacio libre entre los elementos, sin dejar espacio antes del primero ni después del último.
- `SpaceAround`: Deja el mismo espacio alrededor de cada elemento, por lo que en los extremos queda la mitad de espacio que entre dos elementos.
- `SpaceEvenly`: Deja exactamente el mismo espacio entre los elementos y en los extremos.
- `Center`: Agrupa los elementos en el centro del espacio disponible.
- `Start` / `End` (en `Row`) y `Top` / `Bottom` (en `Column`): Agrupa los elementos al principio o al final.
- `spacedBy(8.dp)`: Deja una separación fija entre cada elemento. Es la forma más cómoda de separar elementos sin añadir `Spacer`.

## Más ejemplos de modificaciones

### Modificador de tamaño

```kotlin
@Composable
fun Greeting(name: String) {
    Text(text = "Hello, $name!", modifier = Modifier.size(48.dp))
}
```

En el ejemplo anterior, se utiliza el modificador `size` para que el elemento `Text` ocupe un cuadrado de 48 dp de lado. Esto no cambia el tamaño de la letra (para eso se usa el parámetro `fontSize` o el `style`), sino el espacio que ocupa el composable.

Otros modificadores de tamaño muy utilizados son `fillMaxWidth()`, `fillMaxHeight()` y `fillMaxSize()`, que hacen que el elemento ocupe todo el espacio disponible, y `weight(1f)` dentro de una `Row` o `Column`, que reparte el espacio sobrante entre los elementos de forma proporcional.

### Modificador de altura y anchura

```kotlin
@Composable
fun Greeting(name: String) {
    Text(text = "Hello, $name!", modifier = Modifier.width(100.dp).height(50.dp))
}
```

En el ejemplo anterior, se utilizan los modificadores `width` y `height` para cambiar la anchura del texto a 100 dp y la altura a 50 dp.

### Estilo del texto

```kotlin
@Composable
fun Greeting(name: String) {
    Text(
        text = "Hello, $name!",
        fontWeight = FontWeight.Bold,
        fontSize = 20.sp,
        style = MaterialTheme.typography.titleLarge
    )
}
```

En el ejemplo anterior, el estilo del texto no se cambia con un modificador, sino con los parámetros propios de `Text`: `fontWeight` para ponerlo en negrita, `fontSize` para el tamaño (en `sp`, que respeta el tamaño de letra configurado por el usuario) y `style` para aplicar uno de los estilos de texto del tema.

### Modificador de alineación

En el ejemplo anterior, se utiliza el modificador `align` para centrar el texto dentro del `Box`.

### Modificador de relleno (padding)

```kotlin
@Composable
fun Greeting(name: String) {
```

En el ejemplo anterior, se utiliza el modificador `padding` para añadir un espacio de 16 dp alrededor del texto. En Compose no existe un modificador de margen: el efecto de margen se consigue colocando el `padding` antes de modificadores como `background` o `border`, como vimos al hablar del orden de los modificadores.

También se puede indicar el relleno de cada lado por separado: `Modifier.padding(horizontal = 16.dp, vertical = 8.dp)` o `Modifier.padding(start = 8.dp, top = 4.dp)`.

## Otros ejemplos de funciones componibles de interés

### El uso de Spacer

```kotlin

fun Greeting(name: String) {

        Icon(Icons.Default.Favorite, contentDescription = null)
    }
}
```

En el ejemplo anterior, se utiliza la función `Spacer` para añadir un espacio entre el texto y el icono en una fila horizontal.
