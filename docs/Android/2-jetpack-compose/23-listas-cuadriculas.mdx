# Listas en Compose

En Jetpack Compose, puedes mostrar listas de elementos utilizando los componentes `LazyColumn` y `LazyRow`. Estos componentes te permiten mostrar una lista de elementos de forma eficiente y reactiva.

## LazyColumn

El componente `LazyColumn` te permite mostrar una lista de elementos de forma eficiente y reactiva. Puedes utilizar `LazyColumn` para mostrar una lista de elementos verticales que se cargan de forma perezosa a medida que el usuario se desplaza por la lista.

```kotlin
@Composable
fun ListaVertical() {
    LazyColumn {
        items(100) { index ->
            Text(text = "Elemento $index")
        }
    }
}
```

En el ejemplo anterior, se define un componente `ListaVertical` que muestra una lista de 100 elementos verticales utilizando `LazyColumn`. El método `items()` de `LazyColumn` se utiliza para generar los elementos de la lista en función de un rango de índices.

## Listas a partir de una colección

Lo más habitual no es mostrar un número fijo de elementos, sino los elementos de una lista de datos. Para ello, a `items()` le pasamos directamente la lista:

```kotlin
data class Tarea(val id: Int, val titulo: String)

@Composable
fun ListaTareas(tareas: List<Tarea>, modifier: Modifier = Modifier) {
    LazyColumn(modifier = modifier) {
        items(tareas, key = { tarea -> tarea.id }) { tarea ->
            Text(text = tarea.titulo)
        }
    }
}
```

El parámetro `key` indica un identificador único para cada elemento. No es obligatorio, pero es muy recomendable cuando los elementos se pueden añadir, borrar o reordenar, ya que ayuda a Compose a saber qué elemento es cada uno y a no redibujar la lista entera.

:::warning[Import de `items`]
Si Android Studio marca en rojo `items(tareas)`, hay que importar la función `androidx.compose.foundation.lazy.items`, que es la versión que acepta una lista.
:::

También podemos mezclar elementos individuales con listas usando `item { }`, por ejemplo para añadir una cabecera:

```kotlin
LazyColumn {
    item { Text("Mis tareas", style = MaterialTheme.typography.titleLarge) }
    items(tareas, key = { it.id }) { tarea -> Text(tarea.titulo) }
}
```

## Scroll infinito

El scroll infinito consiste en cargar más elementos (por ejemplo, la siguiente página de resultados de una API) cuando el usuario llega al final de la lista. Para detectarlo, usamos el estado de la lista (`LazyListState`) y `derivedStateOf`:

```kotlin
@Composable
fun ScrollInfinito(
    elementos: List<String>,
    onCargarMas: () -> Unit,
    modifier: Modifier = Modifier
) {
    val listState = rememberLazyListState()

    // true cuando el último elemento visible es uno de los últimos 3 de la lista
    val cercaDelFinal by remember {
        derivedStateOf {
            val ultimoVisible = listState.layoutInfo.visibleItemsInfo.lastOrNull()?.index ?: 0
            ultimoVisible >= listState.layoutInfo.totalItemsCount - 3
        }
    }

    LaunchedEffect(cercaDelFinal) {
        if (cercaDelFinal) onCargarMas()
    }

    LazyColumn(state = listState, modifier = modifier) {
        items(elementos) { elemento ->
            Text(text = elemento, modifier = Modifier.padding(16.dp))
        }
    }
}
```

En el ejemplo anterior, cuando el usuario se acerca al final de la lista se llama a `onCargarMas()`, que normalmente será una función del ViewModel que pide más datos y los añade a la lista. Para casos más complejos existe la librería [Paging 3](https://developer.android.com/topic/libraries/architecture/paging/v3-overview?hl=es-419), que integra la paginación con Compose y Room.

## Elementos personalizados

Puedes utilizar elementos personalizados en las listas de Compose para mostrar elementos más complejos. Para ello, basta con llamar a tu propio composable dentro del bloque de `items()`.

```kotlin
@Composable
fun ListaPersonalizada() {
    LazyColumn {
        items(100) { index ->
            ElementoPersonalizado(index)
        }
    }
}

@Composable
fun ElementoPersonalizado(index: Int) {
    Text(text = "Elemento $index")
}
```

En el ejemplo anterior, se define un componente `ListaPersonalizada` que muestra una lista de 100 elementos utilizando `LazyColumn`. El método `items()` de `LazyColumn` se utiliza para generar los elementos de la lista en función de un rango de índices, y se pasa un componente personalizado `ElementoPersonalizado` como argumento.

## Escuchadores de eventos

Puedes añadir escuchadores de eventos a los elementos de la lista para responder a las interacciones del usuario. Por ejemplo, puedes añadir un escuchador de clics a un elemento de la lista para realizar una acción cuando el usuario haga clic en él.

```kotlin
@Composable
fun ListaConClics() {
    LazyColumn {
        items(100) { index ->
            Text(
                text = "Elemento $index",
                modifier = Modifier.clickable { /* Acción al hacer clic */ }
            )
        }
    }
}
```

En el ejemplo anterior, se define un componente `ListaConClics` que muestra una lista de 100 elementos utilizando `LazyColumn`. Se añade un escuchador de clics al elemento de la lista utilizando el modificador `clickable`.

## Separadores

Puedes añadir separadores entre los elementos de la lista incluyendo un `HorizontalDivider` junto a cada elemento.

```kotlin
@Composable
fun ListaConSeparadores() {
    LazyColumn {
        items(100) { index ->
            Column {
                ElementoPersonalizado(index)
                HorizontalDivider()
            }
        }
    }
}
```

En el ejemplo anterior, se define un componente `ListaConSeparadores` que muestra una lista de 100 elementos utilizando `LazyColumn`. Se añade un separador `HorizontalDivider()` entre cada elemento de la lista.

Si solo queremos dejar espacio entre los elementos, es más sencillo usar el parámetro `verticalArrangement` de la lista: `LazyColumn(verticalArrangement = Arrangement.spacedBy(8.dp))`. Y para dejar espacio al principio y al final sin que se recorte el contenido al hacer scroll, `contentPadding = PaddingValues(16.dp)`.

## Filtrado y ordenación

Puedes filtrar y ordenar los elementos de la lista utilizando funciones de extensión como `filter()` y `sortedBy()`. Estas funciones te permiten realizar operaciones comunes con las listas de forma sencilla y eficiente.

```kotlin
@Composable
fun ListaFiltrada() {
    val numeros = (0..100).toList()

    LazyColumn {
        items(numeros.filter { it % 2 == 0 }) { numero ->
            Text(text = "Número $numero")
        }
    }
}
```

En el ejemplo anterior, se define un componente `ListaFiltrada` que muestra una lista de números pares del 0 al 100 utilizando `LazyColumn`. Se filtran los números pares utilizando la función de extensión `filter()`.

:::tip[Dónde filtrar y ordenar]
En una app real, el filtrado y la ordenación deberían hacerse en el ViewModel (o en la consulta a la base de datos), no dentro del composable, ya que el composable puede recomponerse muchas veces y repetiría el cálculo en cada una.
:::

## Porqué usar LazyColumn y LazyRow en lugar de Column y Row

`LazyColumn` y `LazyRow` son componentes optimizados para mostrar listas de elementos de forma eficiente y reactiva. A diferencia de `Column` y `Row`, que renderizan todos los elementos de la lista de forma inmediata, `LazyColumn` y `LazyRow` renderizan solo los elementos visibles en la pantalla y los elementos que están cerca de la zona visible.

Esto hace que `LazyColumn` y `LazyRow` sean más eficientes en términos de rendimiento y consumo de recursos, especialmente cuando se trabaja con listas grandes o infinitas.

Por lo tanto, es recomendable utilizar `LazyColumn` y `LazyRow` para mostrar listas de elementos en Jetpack Compose, ya que proporcionan una experiencia de usuario más fluida y eficiente.

## Cuadrículas o Grids

En Jetpack Compose, puedes mostrar listas de elementos en forma de cuadrículas utilizando el componente `LazyVerticalGrid` o `LazyHorizontalGrid`. Estos componentes te permiten mostrar una cuadrícula de elementos de forma eficiente y reactiva.

```kotlin
@Composable
fun CuadriculaVertical() {
    LazyVerticalGrid(columns = GridCells.Fixed(3)) {
        items(100) { index ->
            Text(text = "Elemento $index")
        }
    }
}
```

En el ejemplo anterior, `LazyVerticalGrid` muestra 100 elementos en 3 columnas. El parámetro correcto es `columns` (la API antigua `cells` ya no se usa).

```kotlin
@Composable
fun CuadriculaHorizontal() {
    LazyHorizontalGrid(rows = GridCells.Fixed(3)) {
        items(100) { index ->
            Text(text = "Elemento $index")
        }
    }
}
```

En el ejemplo anterior, `LazyHorizontalGrid` muestra 100 elementos en 3 filas mediante el parámetro `rows`.

En lugar de un número fijo de columnas, podemos indicar un tamaño mínimo para cada celda con `GridCells.Adaptive`. Así, la cuadrícula muestra tantas columnas como quepan, lo que la adapta automáticamente a móviles, tablets o la pantalla en horizontal:

```kotlin
LazyVerticalGrid(
    columns = GridCells.Adaptive(minSize = 128.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp),
    verticalArrangement = Arrangement.spacedBy(8.dp)
) {
    items(fotos) { foto -> TarjetaFoto(foto) }
}
```
