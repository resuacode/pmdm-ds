# Material Design en Jetpack Compose

Material Design es un sistema de diseño desarrollado por Google que ayuda a los desarrolladores a crear interfaces de usuario atractivas y coherentes en aplicaciones Android. Con Jetpack Compose, el camino recomendado hoy es **Material 3** (`androidx.compose.material3`).

## Temas y estilos

Compose incluye widgets y estilos basados en Material 3. Puedes personalizar colores, tipografías y formas para adaptarlos a la identidad visual de tu aplicación.

```kotlin
@Composable
fun MiApp() {
    MaterialTheme {
        Column {
            Text(text = "Hola, mundo!", style = MaterialTheme.typography.titleLarge)
            Button(onClick = { /* Acción */ }) {
                Text(text = "Haz clic aquí")
            }
        }
    }
}
```

En el ejemplo anterior, `MaterialTheme` aplica los estilos de Material 3. Se usa `MaterialTheme.typography.titleLarge` (camelCase) para la tipografía y `Button` para un botón con el texto "Haz clic aquí".

## Widgets de Material Design

Algunos de los widgets más comunes en Material 3 son:

- `Button`: Un botón interactivo que el usuario puede pulsar para realizar una acción.
- `TextField` / `OutlinedTextField`: Campos de texto.
- `Checkbox`: Una casilla de verificación.
- `RadioButton`: Un botón de opción entre varias alternativas.
- `Switch`: Un interruptor activar/desactivar.
- `Card`, `TopAppBar`, `NavigationBar`, `FloatingActionButton`: Contenedores y navegación típicos de Material 3.

## Personalización de estilos

Puedes definir tus propios temas con `lightColorScheme` / `darkColorScheme` y pasarlos a `MaterialTheme` mediante `colorScheme` (Material 3). También puedes personalizar `Typography` y `Shapes`.

```kotlin
val MiEsquemaDeColor = lightColorScheme(
    primary = Color(0xFF6750A4),
    onPrimary = Color.White,
    secondary = Color(0xFF625B71),
    tertiary = Color(0xFF7D5260)
)

@Composable
fun MiApp() {
    MaterialTheme(colorScheme = MiEsquemaDeColor) {
        Column {
            Text(text = "Hola, mundo!", style = MaterialTheme.typography.titleLarge)
            Button(onClick = { /* Acción */ }) {
                Text(text = "Haz clic aquí")
            }
        }
    }
}
```

:::tip[Material 2 vs Material 3]
Las APIs antiguas `lightColors()`, `primaryVariant` y `MaterialTheme(colors = …)` pertenecen a **Material 2**. En proyectos nuevos usa Material 3: `lightColorScheme()`, sin `primaryVariant`, y `MaterialTheme(colorScheme = …)`.
:::
