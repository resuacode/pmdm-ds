# El lenguaje C Sharp

C# es un lenguaje de programación orientado a objetos desarrollado por Microsoft como parte de la plataforma .NET. 

Es un lenguaje de programación moderno, de tipado estático y seguro que se utiliza para crear aplicaciones de escritorio, aplicaciones web, aplicaciones móviles y, por supuesto, videojuegos, ya que es el lenguaje de scripting de Unity. 

Si venimos de Java, C# nos resultará muy familiar: la sintaxis, las clases, las interfaces o las excepciones son muy parecidas.

## Sintaxis básica

La sintaxis de C# es similar a la de otros lenguajes de programación como Java y C++.

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}
```

## Tipos de datos en C#

C# es un lenguaje de programación fuertemente tipado, lo que significa que cada variable debe tener un tipo de datos específico.    

Los tipos de datos en C# se dividen en dos categorías: tipos por valor y tipos por referencia.

### Tipos por valor

Las variables de tipos por valor contienen directamente su dato, y al asignarlas a otra variable se copia el valor. Los más utilizados son:

- `int`: Representa un número entero.
- `float`: Representa un número de punto flotante de precisión simple. Es el que más se usa en Unity; sus literales llevan el sufijo `f` (`5.0f`).
- `double`: Representa un número de punto flotante de precisión doble.
- `char`: Representa un carácter Unicode.
- `bool`: Representa un valor booleano (`true` o `false`).
- Las **estructuras** (`struct`) y las **enumeraciones** (`enum`). En Unity, tipos como `Vector2`, `Vector3`, `Quaternion` o `Color` son estructuras.

### Tipos por referencia

Las variables de tipos por referencia guardan una referencia al objeto, por lo que al asignarlas a otra variable ambas apuntan al mismo objeto. Algunos de ellos son:

- `string`: Representa una secuencia de caracteres (inmutable, como en Java).
- `object`: El tipo base del que heredan todos los demás.
- Los **arrays** (`int[]`, `string[]`...): colecciones de tamaño fijo de elementos del mismo tipo.
- Las **clases**, incluidas las colecciones como `List<T>` o `Dictionary<TKey, TValue>` y todos los componentes de Unity (`GameObject`, `Transform`, `Rigidbody2D`...).

```csharp
int vidas = 3;
float velocidad = 5.5f;
string nombre = "Jugador";
var puntos = 0; // var: el compilador deduce el tipo (int)

int[] puntuaciones = { 10, 20, 30 };
List<string> inventario = new List<string> { "Espada", "Escudo" }; // using System.Collections.Generic;

// Interpolación de cadenas, equivalente a las plantillas de Kotlin
Debug.Log($"{nombre} tiene {vidas} vidas");
```

## Estructuras de control

Las estructuras de control en C# permiten controlar el flujo de ejecución de un programa.

### Estructuras de control condicionales

Las estructuras de control condicionales en C# son las siguientes:

- `if`: Permite ejecutar un bloque de código si se cumple una condición.
- `else`: Permite ejecutar un bloque de código si no se cumple la condición del `if`.
- `else if`: Permite evaluar una condición adicional si no se cumple la condición del `if`.
- `switch`: Permite evaluar múltiples condiciones y ejecutar un bloque de código en función del valor de una expresión.

### Estructuras de control iterativas

Las estructuras de control iterativas en C# son las siguientes:

- `for`: Permite ejecutar un bloque de código un número específico de veces.
- `while`: Permite ejecutar un bloque de código mientras se cumpla una condición.
- `do while`: Permite ejecutar un bloque de código al menos una vez y luego repetirlo mientras se cumpla una condición.

## Funciones en C#

Las funciones en C# se utilizan para encapsular un bloque de código que realiza una tarea específica.

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine(Suma(5, 3));
        }

        static int Suma(int a, int b)
        {
            return a + b;
        }
    }
}
```

## Clases y objetos en C#

Las clases y objetos en C# se utilizan para modelar entidades del mundo real. Una diferencia importante con Java son las **propiedades** (`{ get; set; }`), que sustituyen a los métodos `getX()` y `setX()`, de forma parecida a las propiedades de Kotlin.

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Persona persona = new Persona("Juan", 25);
            Console.WriteLine(persona.Nombre);
            Console.WriteLine(persona.Edad);
        }
    }

    class Persona
    {
        public string Nombre { get; set; }
        public int Edad { get; set; }

        public Persona(string nombre, int edad)
        {
            Nombre = nombre;
            Edad = edad;
        }
    }
}
```

:::info[C# en Unity]
En Unity no escribimos un método `Main`: nuestras clases heredan de `MonoBehaviour` y es el motor quien llama a sus métodos (`Awake`, `Start`, `Update`...). Además, para que un campo aparezca en el inspector, Unity necesita que sea un campo `public` o `[SerializeField]`, no una propiedad. Puedes ver más en el apartado de [Scripting en Unity](../1-Unity/9-Scripting.mdx).
:::
